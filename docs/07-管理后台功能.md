# 07 管理后台功能

> 后台 = MineAdmin 自带的登录、管理员、角色、菜单、日志 + 本项目新增的「畅撩交友」业务菜单。
> 页面写法照抄 `admin-web/src/modules/base/views/permission/user`；UI 规则见 `03` 文档第 8 节。
> 后台控制器照抄 `server/app/Http/Admin/Controller/Permission/UserController.php`：必须带 `AccessTokenMiddleware`、`PermissionMiddleware`、`OperationMiddleware` 三个中间件和 `#[Permission(code: ...)]`。

---

## 1. 菜单结构

菜单和权限通过种子文件 `server/databases/seeders/cl_menu_seeder.php` 写入（照抄 MineAdmin 的 `menu_seeder` 写法）。

├── 数据看板

│   ├── 男用户
│   ├── 女用户

├── 审核中心
│   ├── 资料审核
│   └── 实名审核
├── 聊天管理
│   ├── 会话记录

│   ├── 积分流水

│   └── 平台收入

    ├── 等级配置

## 2. 公共组件（`admin-web/src/modules/cl/components/`）

| 组件 | 说明 |
|---|---|
| `ClUserCell` | 头像 + 昵称 + ID + 性别图标（♂ 蓝 / ♀ 粉），点击打开用户详情抽屉 |
| `ClUserDrawer` | 用户详情抽屉（任何页面点用户都打开它）：基本资料、相册、钱包、等级、实名、会员、封禁记录、最近 20 条流水 |
| `ClAmount` | `type` = coin / point / fen，统一格式化 |
| `ClStatusTag` | 传入状态枚举名，统一颜色（03 文档第 8 节第 5 条） |
| `ClImagePreview` | 缩略图 + 点击大图 |
| `ClReasonDialog` | 危险操作的二次确认 + 必填原因输入框 |
| `ClConfigForm` | 配置分组表单：根据 `cl_config` 的 `value_type` 自动渲染输入框（int / string / bool 开关 / json 编辑器） |

## 3. 每个页面的功能

### 3.1 数据看板

- 卡片：今日新增男/女用户、今日活跃用户、今日付费私信条数、今日礼物金币、今日充值金币与实收金额、今日平台毛收入（元）、待审资料数、待审实名数、待处理举报数、待审消息数、待审核提现数与金额。
- 图表：近 30 天每日充值实收、平台毛收入、新增用户（用 `@mineadmin/echarts`）。
- 待办卡片可以点击跳到对应页面。

### 3.2 男用户 / 女用户（同一个页面组件，`gender` 参数不同）

- 搜索：ID、账号、手机号、昵称、状态、注册来源、批次号、注册时间范围；女用户多「等级」「实名状态」；男用户多「是否会员」。
- 列：`ClUserCell`、账号、手机号、城市、状态、注册来源、注册时间、最后活跃；男：金币余额、累计充值、会员到期；女：等级（锁定图标）、积分余额、冻结积分、累计收益、实名状态。
- 操作：
  - 查看详情（抽屉）
  - 编辑资料（可直接改昵称/头像/简介，绕过审核，写操作日志）
  - 重置密码（生成随机密码弹窗显示一次）
  - 封禁（选 1 天 / 3 天 / 7 天 / 30 天 / 永久 + 原因）/ 解封
  - 女用户：调整等级（选等级 + 是否锁定 + 原因）
  - 男用户：开通会员（选套餐或填天数 + 备注）
  - 超级管理员：修改性别（二次确认 + 原因）、金币扣减、积分调整
- 导出当前搜索结果为 Excel（不导出密码和身份证）。

### 3.3 批量开号

- 表单：性别（男/女）、数量（1~200）、账号前缀（默认男 `M` 女 `F`）、备注。
- 选女号时，表单上方固定显示提示：「每个女号只能由一名真实的签约陪聊人员使用，资料和照片必须是本人真实信息。」
- 提交后生成批次，弹窗显示账号与明文密码列表 + 「下载 CSV」按钮，**关闭弹窗后无法再次查看明文密码**（只能对单个账号重置密码）。
- 批次列表：批次号、性别、数量、操作人、时间、备注、是否已导出；点击查看批次内账号（跳转到用户列表并按批次号筛选）。

### 3.4 资料审核

- Tab：待审核 / 已通过 / 已驳回。
- 列：用户、字段（头像/昵称/简介/相册）、旧值、新值（图片显示缩略图）、提交时间。
- 操作：通过、驳回（选常用原因或手填）；支持勾选批量通过/驳回。
- 通过后更新 `cl_user` 对应字段并通知用户；驳回只通知。

### 3.5 实名审核

- Tab：审核中 / 已通过 / 已驳回。
- 列：用户、真实姓名、身份证号（默认打码，点「查看」显示明文并写操作日志）、提交时间、同身份证号的其他账号数（`id_card_hash` 查重，只提示不拦截）。
- 操作：通过、驳回（必填原因）。

### 3.6 会话记录

- 搜索：用户 ID（任一方）、时间范围。
- 列：男方、女方、男方已发条数、最后消息时间。
- 点击进入消息详情：按时间显示全部消息（文字、图片、礼物），每条显示价格、免费原因、女方所得积分；可在任意消息上「标记违规」（同待审消息处理）。

### 3.7 待审消息

- 命中敏感词的消息（`review_status = 1`）。
- 列：发送方、接收方、内容（命中的词标红）、时间。
- 操作：标记正常、标记违规（可同时封禁发送方，选天数+原因）。批量操作。

### 3.8 敏感词库

- 增、删、改、启停；批量导入（每行一个词的文本框）。修改后清除服务端敏感词缓存。

### 3.9 举报处理

- Tab：待处理 / 已处理。
- 列：举报人、被举报人、原因、描述、截图、关联消息（点击查看上下文 10 条）、时间。
- 操作：判定违规（可同时封禁）/ 判定不违规，填处理结果；处理后通知举报人。

### 3.10 后台充值

- 表单：用户（输入 ID/账号搜索，**只能选男用户**，选中后显示昵称和当前余额）、金币数量、实收金额（元）、支付方式（微信/支付宝/其他/赠送）、备注。
- 「金币数量」旁显示按 `coin.per_yuan` 换算的参考金额。
- 提交前二次确认弹窗显示：用户、充值金币、实收金额。

### 3.11 充值记录

- 搜索：用户、操作人、支付方式、时间范围。列：单号、用户、金币、实收金额、支付方式、操作人、备注、时间。底部合计金币与实收。

### 3.12 金币流水 / 积分流水

- 搜索：用户、类型、时间范围。列：用户、类型、变动、变动后余额（积分流水多冻结变动、冻结后）、标题、关联单号、操作人、时间。只读。

### 3.13 提现审核

- Tab：待审核 / 待打款（已通过）/ 已打款 / 已驳回。
- 列：单号、用户（含等级、实名姓名）、申请金额、手续费、实际到账、冻结积分、收款方式、收款账号、收款人、申请时间。
- 操作：
  - 待审核：通过 / 驳回（必填原因）
  - 待打款：标记已打款（必填打款流水号或备注）/ 驳回
- 底部显示当前筛选的金额合计。导出 Excel（给财务打款用）。

### 3.14 平台收入

- 按天汇总：日期、私信收入金币、礼物收入金币、会员收入金币、发给女用户积分、平台毛收入（元）。可按日期范围查询，可导出。

### 3.15 计费与分成

- `ClConfigForm` 展示 group = billing / share / chat / vip 的所有配置项，每项旁边显示说明（`remark`）。
- 页面顶部显示一个**计算示例**（随输入实时更新）：「Lv1 女用户（已实名）收到 1 条私信：男方 −5 金币，女方 +15 积分（¥0.15），平台留 ¥0.35」。
- 保存时校验：比例 0~10000、免费条数 ≥ 0、汇率 > 0。

### 3.16 等级配置

- 5 行表格直接编辑：等级名称、升级门槛、私信单价、私信分成、语音单价、视频单价。
- 校验：门槛必须递增、Lv1 门槛为 0、单价 ≥ 0、分成 0~10000。
- 页面说明：「修改单价只影响之后的消息；修改门槛不会让已升级的用户降级」。

### 3.17 礼物管理 / 会员套餐 / 每日任务

- 标准增删改查 + 启停 + 排序。礼物可上传图标图片或填 emoji。
- 任务的「类型」只能选 06 文档第 7 节列出的 4 种。

### 3.18 会员开通记录

- 列：单号、用户、套餐、天数、金币、来源（购买/后台）、开通前到期、开通后到期、操作人、时间。

### 3.19 充值档位与客服

- 充值档位：表格编辑（金币、价格元），保存为 `recharge.packs` JSON。
- 客服信息：微信号、二维码图片（上传）、电话。

### 3.20 系统通知

- 发布全员公告（标题、内容）或给指定用户发通知（输入用户 ID，可多个）。
- 已发布列表。

### 3.21 协议与声明

- 用户协议、隐私政策（富文本或多行文本）、合规声明 `compliance.disclosure`（不能为空）。

### 3.22 兴趣标签与城市

- 两个简单列表的增删改、排序、启停。

### 3.23 功能开关

- `feature.call_enabled`（语音/视频入口），开关旁边写明「打开后只显示页面，拨打会提示功能暂未开放」。
