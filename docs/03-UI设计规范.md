# 03 UI 设计规范（写任何界面前必读）

> 目标：31 个页面看起来像**同一个人**做的。做到这一点只有一个办法：
> **页面里只准组合公共组件，不准自己画样式。**
>
> 所有数值从 HTML 原型 `遇见你-收费聊天版.html` 的 CSS 提取。原型宽 390px，换算到安卓 1px = 1dp。

---

## 1. 三条硬规则

1. **颜色**只能用 `ClTheme.colors.xxx`；**字号/字重**只能用 `ClTheme.typography.xxx`；**间距/尺寸**只能用 `ClTheme.spacing.xxx` / `ClTheme.size.xxx`；**圆角**只能用 `ClTheme.shapes.xxx`。
2. `feature/` 目录下的代码**禁止出现**：`Color(`、`.dp`、`.sp`、`FontWeight.`、`RoundedCornerShape(`、`MaterialTheme.`、`androidx.compose.material3.Button`、`TextField(`、`OutlinedTextField(`、`AlertDialog(`、`ModalBottomSheet(`、`Snackbar(`。这些只能在 `core/designsystem/` 里出现。`scripts/check-ui.sh` 会扫描，扫到就不通过。
3. 页面缺组件时：**先在 `core/designsystem/component/` 新增组件，并加到组件预览页（第 7 节）**，再在页面里使用。

后台（admin-web）的规则见第 8 节。

## 4. 间距、尺寸、圆角

**ClSpacing（dp）**：`xxs=2` `xs=4` `s=8` `m=12` `l=16` `xl=20` `xxl=24` `xxxl=32`

- 页面左右边距统一 `l`（16dp）。
- 卡片内边距统一 `l`（16dp）。
- 列表项之间 `m`（12dp），区块之间 `xl`（20dp）。

**ClSize（dp）**

| Token | 值 | 用途 |
|---|---|---|
| `topBarHeight` | 56 | 内页顶栏 |
| `bottomBarHeight` | 68 | 底部导航 |
| `buttonHeight` | 46 | 主按钮 |
| `buttonHeightSmall` | 32 | 卡片里的小按钮 |
| `inputHeight` | 44 | 输入框 |
| `menuRowHeight` | 55 | 菜单行 |
| `avatarL` / `avatarM` / `avatarS` / `avatarXS` | 72 / 60 / 50 / 30 | 我的页 / 发现卡片 / 列表 / 聊天气泡 |
| `iconM` / `iconS` | 22 / 17 | 图标 |
| `onlineDot` | 13 | 在线点 |
| `coverHeight` | 290 | 详情页封面 |

**ClShapes**：`pill=50%`（按钮、Chip、胶囊）、`card=15dp`、`cardSmall=12dp`、`input=10dp`、`sheet=23dp`（只上两角）、`bubbleMine=13/13/4/13`、`bubbleOther=13/13/13/4`、`photo=8dp`、`circle`。

**阴影**：只用一种卡片阴影 `ClElevation.card`（Y 偏移 5dp、模糊 20dp、颜色 `#F5F1EB`），用 `Modifier.clCardShadow()` 统一调用。

## 6. 页面统一规则

1. **一级页面**（P01 P03 P04 P02）：顶部用 `gradientTopWash` + `ClPageHeader`，底部用 `ClBottomBar`。
2. **二级页面**：一律用 `ClTopBar`（返回 + 标题），背景白色或 `bgPage`。
3. **每个有数据的页面都要处理四种状态**：`Loading → ClLoading`、`Empty → ClEmpty`、`Error → ClErrorRetry`、`Content`。列表页的分页加载失败显示在列表底部，不覆盖整个页面。
4. **按钮防重复点击**：提交类按钮在请求中显示 loading 并禁用。
5. **文案统一**：
   - 金币写「金币」，简写「币」只用在价格里（`5 币/条`）。
   - 积分写「积分」，人民币写「¥12.50」（两位小数）。
   - 时间：今天显示 `HH:mm`，昨天显示「昨天 HH:mm」，今年显示 `MM-dd HH:mm`，更早显示 `yyyy-MM-dd`。统一用 `core/common/TimeFormat.kt`。
   - 错误提示直接显示服务端 `message`，网络错误统一显示「网络不太好，请稍后重试」。
6. **图标**：全部用 `ClIcons`（基于 Material Icons Rounded，线条风格），原型里用到的图标（home、heart、message、user、search、filter、pin、chevron、back、bell、eye、star、wallet、shield、settings、calendar、edit、mic、phone、video、gift、check、more、spark、speaker、flip）都要在 `ClIcons` 里有对应。
7. **图片**：头像、相册统一用 `ClAvatar` / `ClPhotoGrid`，内部用 Coil，统一占位色 `#E8D8C7`。
8. **无障碍**：所有图标按钮都要有 `contentDescription`；可点击区域不小于 48dp。
9. **状态栏**：一级页面透明融入顶部渐变；二级页面 `bgCream`；通话页深色。

## 7. 组件预览页（必须做）

- 在 debug 包里加一个隐藏页面 `DesignSystemGalleryScreen`，入口：设置页连续点击版本号 5 次。
- 页面按第 5 节顺序展示**所有**公共组件的所有状态（例如按钮的正常/禁用/加载中）。
- 每新增一个组件，必须同时加到预览页。
- 每个阶段结束时截图预览页，和设计图对比一次。

## 8. 管理后台 UI 规则（admin-web）

1. 只用 MineAdmin 自带组件：列表页用 `MaProTable`（含搜索区），表单用 `MaForm`，弹窗用 MineAdmin 的弹窗写法。**禁止自己写原生 `<table>` 和自定义样式表格。**
2. 所有列表页结构一致：**搜索区 → 工具栏（新增/批量操作/导出）→ 表格 → 分页**。照抄 `src/modules/base/views/permission/user` 的写法。
3. 用户信息列统一用 `ClUserCell`（头像 + 昵称 + ID + 性别图标）。
4. 金额列统一用 `ClAmount`：金币显示「1,280 金币」，积分显示「1,500 积分」，人民币显示「¥15.00」。
5. 状态列统一用 `ClStatusTag`，颜色固定：待处理 = warning（橙）、通过/成功/已打款 = success（绿）、驳回/失败/封禁 = danger（红）、关闭/过期 = info（灰）。
6. 危险操作（封号、驳回、扣金币、批量开号）必须二次确认，并要求填写原因。
7. 时间列格式 `YYYY-MM-DD HH:mm:ss`。
8. 不改 MineAdmin 的主题色和布局。
