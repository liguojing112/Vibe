# 04 数据库设计

> MySQL 8，字符集 `utf8mb4`，引擎 InnoDB。所有业务表前缀 `cl_`。
> 每张表都有：`id`（bigint unsigned 自增主键）、`created_at`、`updated_at`（datetime）。下文不再重复列出。
> 每张表一个迁移文件；改表只能新建迁移，不准修改已执行过的迁移。
> 金额、积分、比例一律 `bigint` 或 `int`，**禁止 decimal/float 存金币积分**；人民币金额用「分」存 `bigint`（字段名以 `_fen` 结尾）。

## 7. 后台批量开号

### cl_batch_account

`batch_no varchar(32) unique`、`gender tinyint`、`count int`、`account_prefix varchar(8)`、`operator_id`、`remark`、`exported tinyint`（明文密码导出后置 1）。

- 账号规则：`前缀 + 8 位数字`（例如 `F10000001`），前缀默认女号 `F`、男号 `M`，保证唯一。
- 密码：随机 8 位（大小写字母 + 数字），bcrypt 存入 `cl_user`；明文**只在生成后立即返回一次**并提供 CSV 下载，服务端不保存明文。
- 批量号默认资料：昵称「用户 + 账号后 4 位」，无头像。**无头像的账号不会出现在发现页**，必须由使用者本人登录后上传本人照片、通过审核后才展示。
