# 收费聊天产品参考与设计假设

本次将产品定位调整为一对一付费聊天，补齐语音、视频、虚拟币消费和接听方收益流程。

## 查阅的公开资料

- [他趣官方《社交付费说明》](https://market-h5.taqu.cn/html/faq/detail-227.html?v=1657074583)：介绍私信单条计价、语音与视频按分钟计价，以及拨打页面展示费用。本原型借鉴“先展示单价、再发起沟通”的流程。
- [他趣官方《奖励说明》](https://market-h5.taqu.cn/html/faq/detail-90.html?v=1654137298)：包含互动、通话和礼物相关收益。本原型据此补充接听方收益与提现界面；具体分成未套用竞品规则。
- [觅伊官网](https://miyiapp.com/) 与 [觅伊 App Store 页面](https://apps.apple.com/us/app/id1493053100)：用于了解真人社交和内购产品结构。

以上仅用于梳理同类产品功能；不同产品、地区、版本的规则可能不同。

## 当前原型假设

| 项目 | 当前展示 |
|---|---|
| 私信 | 5 金币/条 |
| 一对一语音 | 60 金币/分钟 |
| 一对一视频 | 120 金币/分钟 |
| 充值兑换 | 1 元 = 10 金币 |
| 通话起计 | 接通后才开始 |
| 分钟边界 | 每开始一分钟扣一次，不足一分钟按一分钟 |
| 余额耗尽 | 无法支付下一分钟时自动结束 |
| 礼物 | 按面板标价单独扣费 |
| 会员 | 不自动抵扣聊天费 |
| 收益提现 | 收益豆独立展示，示例 100 豆 = 1 元，50 元提现档位 |

这些数字均为方案示例，不代表竞品价格，也不是已确认的商业规则。消费金币与接听收益分开记账；收益中心演示的是接听方视角，不能直接将本账号支出的金币视为本账号的收入。

## 后续需要业务确认

谁在每段关系中承担费用、互关后是否免费、未回复消息是否退费、通话单价范围、免费体验时长、退款规则、接听方分成、结算周期及提现门槛。

## 演示边界

音视频为人物示意图和控件状态，计时与扣币在浏览器中模拟。语音静音、扬声器、摄像头切换只展示界面状态。真实通话、支付、提现与实名服务需要另外接入。正式计费应在服务端完成，不能依赖本原型浏览器计时。
