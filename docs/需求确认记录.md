# 需求确认记录

> 这份文件记录 Yancy 逐条确认过的需求，是写开发文档的依据。
> 只记录已确认的结论；没确认的写在最后的「待确认」里。

## 第 1 轮（2026-10-10）

| 编号 | 问题 | 结论 |
|---|---|---|
| R1-1 | 音视频通话、发语音 | 暂时隐藏，本期不做。代码里预留入口开关，默认关闭 |
| R1-2 | 支付方式 | 不接微信、支付宝。只做「后台充值」：管理员在后台给用户加金币，每笔留记录 |
| R1-3 | 谁付费 | 男用户付费，女用户获得收益 |
| R1-4 | 安卓 UI 框架 | Kotlin + Jetpack Compose |
| R1-5 | 后端和管理后台 | MineAdmin 3.x（Hyperf 3 + PHP 8.1+ + Swoole；后台前端 Vue3 + TS） |
| R1-6 | 后台用户管理 | 要有用户管理，支持批量开通女号、批量开通男号 |
| R1-7 | 收费规则 | 前 N 条免费、每条扣多少积分、1 积分值多少钱，后台都能调；按等级分档，不同等级单价和分成不同。参考语聊行业做法 |

## 第 2 轮（2026-10-10）

总原则：对标产品是「伊对」。所有数字、比例、开关都必须能在后台配置，代码里不能写死。

| 编号 | 问题 | 结论 |
|---|---|---|
| R2-1 | 等级分成指什么 | 男用户付费，女用户拿到积分。要拆成三块：男用户付多少、平台抽多少、女用户拿多少，比例按女用户等级分档 |
| R2-2 | 单价谁定 | 先参考行业做法（待第 3 轮确认） |
| R2-3 | 免费条数 | 后台可配置 |
| R2-4 | 互关免费 / 12 小时未回复退币 / 未实名分成减半 | 三项都做，每项后台可开关、可调参数 |
| R2-5 | 等级升级 | 按累计收益自动升级，后台也能手动调 |
| R2-6 | 礼物 | 做，分成方式参考行业 |
| R2-7 | 男用户充值 | App 显示「联系客服充值」和充值档位（只做展示），管理员在后台加金币 |
| R2-8 | 女用户提现 | App 提交申请 → 后台审核 → 线下打款 → 后台点「已打款」。最低金额、档位、次数等提现规则全部在后台配置 |
| R2-9 | 提现前实名 | 要。填姓名 + 身份证号，后台人工审核 |
| R2-10 | 批量开号 | 填数量，系统自动生成账号和密码 |
| R2-11 | 登录 | 手机号 + 密码，不做短信验证码 |
| R2-12 | 批量女号给谁用 | 给公司的「女聊手」使用（合规条件待确认，见待确认 Q3-1） |
| R2-13 | 公会 / 经纪人 | 不做 |
| R2-14 | 聊天审核 | 要：查看会话记录、敏感词过滤、处理举报、封号 |

## 第 3 轮（2026-10-10）

| 编号 | 问题 | 结论 |
|---|---|---|
| R3-1 | 分成默认值 | 参考他趣：礼物 34%，未实名打折，其余归平台，全部后台可调。私信分成按等级，以 R3-4 为准 |
| R3-2 | 女聊手账号 | 1 人 1 号；不做多号登录的技术限制（其余合规条件待确认，见 Q4-1） |

| R3-4 | 等级数量 | 5 级。默认私信分成 1~5 级为 30%/35%/40%/45%/50%；未实名乘 0.5；礼物单独设比例，默认 34%，不随等级变化。全部后台可调 |
| R3-5 | 免费条数 | 按「每对男女」计算，默认前 3 条免费，后台可调 |
| R3-6 | 女用户发消息 | 永远免费 |
| R3-7 | 后台角色 | 超级管理员、客服（充值、处理举报）、财务（审核提现、标记打款）、审核员（查看聊天、封号） |
| R3-8 | 语音/视频相关 8 个页面 | 页面要做出来，功能不做（具体展示方式见 Q4-4） |
| R3-9 | 每日任务、会员中心、最近访客、喜欢我的人 | 本期都要做 |

## 行业参考（已查）

以他趣官方公开规则为例，供定方案时对照，不直接照搬：

- [社交付费说明](https://market-h5.taqu.cn/html/faq/detail-227.html?v=1657074583)：男用户主动私信付费；单价按接收方魅力等级在一个区间内设定；某些场景前 20 条免费；互相关注后文字免费；消息 12 小时没回复自动退币。
- [奖励说明](https://market-h5.taqu.cn/html/faq/detail-90.html?v=1654137298)：接收方拿付费消息价值的固定比例作收益，真人认证的比例更高；礼物也按比例分成；公会成员按公会约定比例；提现要实名，分小额和大额档位，限制提现次数。

- 伊对：搜索了公开资料，没有找到它官方的私信计费和分成规则页面，具体数字未核实。已请 Yancy 提供伊对 App 内规则页截图。
