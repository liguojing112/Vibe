## 2. 后端 server/（MineAdmin 3.2）

### 2.1 初始化

```bash
git clone --branch v3.2.0 --depth 1 https://github.com/mineadmin/MineAdmin.git server
cd server && composer install && cp .env.example .env    # 填好 .env 里的 MySQL / Redis
php bin/hyperf.php mine:install                         # 会执行 migrate 和 db:seed
composer require hyperf/websocket-server:"3.2.*"        # WebSocket 推送需要
```

删除 `server/.git`，让它成为本仓库的普通目录。

### 2.2 分层规则（必须模仿 MineAdmin 自带的 User/Role 写法）

| 层 | 目录 | 职责 | 禁止 |
|---|---|---|---|
| Controller | `app/Http/Api/Controller/V1/`（App 接口）、`app/Http/Admin/Controller/Cl/`（后台接口） | 收参数、调 Service、返回结果 | 写业务逻辑、写 SQL |
| Request | `app/Http/Api/Request/V1/`、`app/Http/Admin/Request/Cl/` | 参数校验 | |
| Service | `app/Service/Cl/` | 业务逻辑、事务 | 直接返回 HTTP 响应 |
| Repository | `app/Repository/Cl/` | 数据库查询 | 写业务判断 |
| Model | `app/Model/Cl/` | 表映射 | |
| Enum | `app/Model/Enums/Cl/` | 状态、类型常量 | |
| Schema | `app/Schema/Cl/` | Swagger 文档结构 | |

「Cl」是本项目业务代码的命名空间前缀，所有业务代码都放在 `Cl` 子目录里，**不准改 MineAdmin 自带的文件**（路由注册、配置文件除外）。

### 2.4 关键约定

- **App 用户和后台管理员是两张表**：App 用户用 `cl_user`，后台管理员用 MineAdmin 自带的 `user` 表。App 的 JWT 用单独的 scene（`api`），密钥与后台不同。
- **改金币只能调 `CoinWalletService`，改积分只能调 `PointWalletService`**。其他任何地方出现 `UPDATE cl_coin_wallet` 都是错的。
- **读配置只能调 `AppConfigService::get(key)`**。配置有 Redis 缓存，后台修改后清缓存。
- 事务用 `Db::transaction()`；余额行用 `lockForUpdate()`。
- 所有时间存 `datetime`，时区 `Asia/Shanghai`。
- WebSocket：在 `config/autoload/server.php` 增加一个 `ws` 服务（端口 9502，路径 `/ws`），用 `hyperf/websocket-server`。连接时用 query 里的 token 鉴权；`用户ID → fd` 存 Redis。消息推送由 `PushService` 统一负责。本期按**单台服务器部署**设计。
- 图片上传：存 `server/storage/uploads/cl/{yyyymm}/{随机名}.{ext}`，通过 `StorageInterface` 读写，返回可访问 URL。只允许 jpg/png/webp，最大 5MB，服务端校验真实文件类型。

## 4. 安卓 android/

### 4.1 基本信息（暂定，集中写在 `app/build.gradle.kts`，以后可改）

- applicationId：`com.qichuang.changliao`
- App 名称：畅撩交友（`strings.xml` 的 `app_name`）
- minSdk 26，targetSdk / compileSdk 用当前最新稳定版
- 单模块 `app`，按包分层（不用多模块，降低复杂度）

### 4.2 依赖（版本全部写在 `gradle/libs.versions.toml`，写死版本号）

测试：JUnit4、kotlinx-coroutines-test、MockK、Turbine、OkHttp MockWebServer。

### 4.4 关键约定

- 页面状态统一用 `sealed interface UiState { Loading; Empty; Error(msg); Content(data) }` 模式（放在 `core/common/UiState.kt`）。
- ViewModel 不能引用 Android `Context`，不能直接用 Retrofit。
- 所有金额、价格只显示服务端返回的数字，用 `core/common/MoneyFormat.kt` 格式化。
- 网络地址写在 `BuildConfig`：debug 指向本机（模拟器 `http://10.0.2.2:9501`），release 从 `gradle.properties` 读。
- debug 包允许明文 HTTP（`network_security_config` 只对 debug 生效），release 必须 HTTPS。
- 图片上传前压缩：长边不超过 1080px，质量 80，JPEG。
- WebSocket：App 在前台时保持连接；每 30 秒心跳；断线后按 1s、2s、4s… 最大 30s 重连；重连成功后调用一次「拉取未读消息」接口补齐。
- **聊天记录以本地库（Room）为主数据源**：界面从本地读；服务端只做转发、计费与监管，**不作为展示数据源**（客户 2026-10-11 确认）。
- **发送用乐观 UI**：先写本地 `sending` 并立即出气泡，成功用服务端返回替换，失败置 `failed` 可重发（`client_msg_id` 重发时**保持不变**）；App 被杀时超过 60 秒仍 `sending` 的下次启动改 `failed`。
- **列表页统一 stale-while-revalidate**：先渲染本地持久化数据（`LocalCache` / Room），再静默刷新替换；不设 TTL，解码失败当作无缓存，缓存键带版本号与 userId，切换账号先清内存。
- 图片缓存用 **Coil**（不自建一套）：显式指定显示尺寸、上传成功后预热、跨主机跳转去掉 `Authorization`。
